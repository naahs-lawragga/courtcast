# CourtCast v4

Static cross-device WebRTC screen sharing. Deploy at Vercel with the Other framework preset and no build command. Sender needs getDisplayMedia; viewer needs WebRTC. Desktop browsers generally support both; Android browsers generally support viewing only. iOS 27 Safari supports capture, subject to OS and browser restrictions. Audio is optional and not guaranteed. School policies and protected media are respected. No direct USB capture, TURN relay, or native app included. Public PeerJS signaling and STUN are used. Keep session codes private. 

Connect this repository to Vercel to deploy automatically on commits to main. No background deployment is managed by ChatGPT.
